# 🎵 Spotify Clone

This is a **frontend clone** of the popular music streaming app **Spotify**, built using only **HTML, CSS, and JavaScript**. It simulates key UI elements and basic functionality like playing/pausing tracks, updating the progress bar, and switching songs.

---

## 📁 Features

- 🎧 Clean and responsive Spotify-like interface
- ⏯️ Play/pause functionality
- 📃 Playlist with multiple songs
- ⏮️⏭️ Next/previous song controls
- 🔘 Seek bar that syncs with audio
- ✨ Vanilla JS used — no frameworks!

---

## 💻 Technologies Used

- **HTML5** – Markup structure
- **CSS3** – Styling and layout
- **JavaScript (ES6)** – Functionality and interactivity
